# Desktop Repository

This repository contains desktop shortcuts, configuration files, and AI-ANTONIOS-INTELIGENCE project files.

## Contents

- **AI-ANTONIOS-INTELIGENCE/**: Main project directory
  - `ToneBone.html`: Web interface for Tone Bone's Cipher Classroom
  - `my raps/`: Collection of lyrics and rap compositions
  - `.env`: Environment configuration (gitignored)
  - `.gitignore`: Git ignore patterns for this directory

- **Documents/**: Document storage and backups
  - `Peace automatic configurations backup/`: Audio equalizer configurations
  - `AI-ANTONIOS-INTELIGENCE/`: Duplicate project files

- **shortcuts/**: Windows shortcut (.lnk) files for quick access to applications

## Git Configuration

The repository includes `.gitignore` files to protect sensitive data:
- Environment variables (`.env` files)
- Node.js dependencies (`node_modules/`)
- Build outputs
- OS-specific files
- IDE configuration files

## Checking for Uncommitted Changes

To check if there are any uncommitted changes in the repository, run:

```bash
bash check-uncommitted.sh
```

This script will:
- ✓ Confirm if the working tree is clean
- ✗ Alert if there are uncommitted changes
- Show which files have been modified
- Provide instructions for committing changes
